# Rooted

Rooted is a Java-based gardening community platform where users can share gardening tips, participate in discussions, and showcase their personal gardening projects.

## Project Overview

Rooted aims to bring gardening enthusiasts together to learn, share experiences, and connect through their interest in gardening.

## Planned Features

- User Profiles: Personal profiles for gardening enthusiasts.
- Gardening Tips: Share useful advice and learn from others.
- Community Discussions: Discuss gardening topics with fellow users.
- Personal Projects: Showcase individual gardening projects.
- Administration: Manage users and moderate community content.

## Technology Stack

- Java
- HTML and CSS
- JavaScript
- MySQL
- Maven

The technology stack and features are planned and may evolve during development.
